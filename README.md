# CampoMinado

## Uma versão básica do jogo "Campo minado" 
Para estudantes da linguagem C#, programadores iniciantes e entusiastas que estão estudando matrizes e vetores. O código servirá como material prático.
Sinta-se a vontade para modificá-lo (Tô ansioso para ver sua criatividade kkkkkk)


###Dinânica do jogo

A dinânica é simples. Ao executar o programa, uma matriz 10x10 aparecerá na tela do terminal junto a mensagem com uma caixa de entrada pedindo para digitar um número de 1 a dez, selecionando a linha.
Após digitar e dar enter, ele pedirá novamente para selecionar a coluna. 
![image](https://github.com/user-attachments/assets/95c56514-0b51-4b4b-b2a2-f273586a1b21)
Se não pegar uma bomba, o jogo continua com uma nova tambela, mas com o nume zero na posição escolhida.
![image](https://github.com/user-attachments/assets/301d85fd-be50-4317-b982-b3540fa4e67a)
Caso pegue uma bomba, o jogo exibirá uma mensagem e o programa finaliza.
![image](https://github.com/user-attachments/assets/38207d75-e7d2-44c0-8cd8-cb08dabecff9)
